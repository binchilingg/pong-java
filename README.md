# Pong em Java

Um jogo de Pong para dois jogadores, feito em Java com Swing. Este projeto está em desenvolvimento e serve como exercício para aprender programação orientada a objetos, desenho na tela, eventos de teclado, animação e colisões.

## Recursos atuais

- Arena redimensionável
- Duas raquetes controladas pelo teclado
- Bola com movimento e colisões
- Placar para os dois lados

## Como executar

É necessário ter o JDK instalado. No terminal, dentro da pasta do projeto:

```powershell
javac --release 8 Pong.java
java Pong
```

## Controles

| Jogador | Subir | Descer |
| --- | --- | --- |
| Esquerda | W | S |
| Direita | Seta para cima | Seta para baixo |
